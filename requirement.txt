⚠️ But here’s the part people miss (important)

Reducing imgsz at export does NOT magically retrain the model.

It only changes:

how the model expects and processes input at inference time

So what actually happens is:

model learned at 640 (high detail)
now it runs at 320 (lower detail)

👉 This is where accuracy drop can happen, especially for:

small people far away
partial occlusions




🔍 What mAP50 actually measures

Precision → how many detections are correct
Recall → how many objects you found
IoU ≥ 0.5 → bounding box overlap requirement

👉 It evaluates the entire detection pipeline
